Software Developer – Battery Storage Control Systems



2022-2023

Python FastAPI MQTT InfluxDB Redis AWS IoT Greengrass Docker scikit-learn

Energy Toolbase's Advanced Energy Storage System is a distributed edge-control platform that orchestrates real-time charge/discharge decisions for commercial battery energy storage, deployed across multi-site utility-scale and behind-the-meter solar+storage installations. I worked across the platform's two core control services, its forecasting integration, and the data-quality safeguards that keep a fleet of edge devices reporting trustworthy numbers.

Key Accomplishments

🔋 Battman — Battery Management Controller

  • Built the platform's central decision engine, orchestrating charge/discharge commands to inverters and batteries via HTTP and MQTT
  • Implemented and maintained 15+ optimization strategies — demand shaving, time-of-use arbitrage, PV self-consumption, demand-response load following, and closed-loop safe-charging control — selectable at runtime with zero-downtime switching
  • Modeled utility tariff structures (multi-tier TOU periods, ratchet demand clauses, seasonal rate changes) to drive cost-minimizing dispatch decisions

📊 Meter Service — Grid Load Aggregation

  • Built the platform's authoritative source of site load data, normalizing readings from 5+ Modbus meter vendors and cloud APIs into a single consistent stream
  • Designed cumulative energy tracking with automatic 64-bit counter rollover detection, and billing-aligned demand-peak tracking with crash-safe persistence
  • Built a pluggable source interface so new meter vendors could be added with a device mapping file rather than new integration code

🤖 Forecasting Integration

  • Integrated scikit-learn–based load and solar forecasting into the control loop, enabling predictive battery state-of-charge positioning ahead of demand peaks and rate transitions
  • Closed the loop from measured load through forecast to dispatch decision, with real-time forecast correction as new actuals arrived

🛡️ Data Quality & Reliability

  • Enforced schema validation at every service boundary (device configs, API contracts, inter-service messages) to reject misconfigured deployments before they reached hardware
  • Built scheduling-constraint validation to prevent overlapping or invalid control windows across concurrent strategies
  • Added automated gap-fill and resampling for cloud-synced meter data, ensuring forecasting models trained on complete, aligned time series
